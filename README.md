# 🔢 Serie Fibonacci - Múltiples Lenguajes

Proyecto de portafolio que demuestra la implementación de la serie Fibonacci en múltiples lenguajes de programación.

## 📋 Descripción

Este proyecto implementa la secuencia de Fibonacci utilizando diferentes métodos y algoritmos en los siguientes lenguajes:

- **Python** 🐍
- **Java** ☕
- **JavaScript** 📜
- **C#** 💜
- **PHP** 🐘

Cada implementación incluye múltiples métodos de cálculo:
- Iterativo
- Recursivo con memoización
- Generador/Yield
- Programación dinámica

## 🚀 Inicio Rápido

### Python
```bash
cd python
python3 fibonacci.py
```

### Java
```bash
cd java
javac Fibonacci.java
java Fibonacci
```

### JavaScript (Node.js)
```bash
cd javascript
node fibonacci.js
```

### C#
```bash
cd csharp
dotnet run
```

### PHP
```bash
cd php
php fibonacci.php
```

### Aplicación Web
Abre `frontend/index.html` en tu navegador para ver la demostración interactiva.

## 🧮 Métodos Implementados

### 1. Iterativo
El método más eficiente en términos de memoria. Utiliza un bucle simple para calcular cada término.

### 2. Recursivo con Memoización
Implementación elegante que utiliza recursión con cache para evitar cálculos repetidos.

### 3. Generador
Utiliza funciones generadoras para producir valores bajo demanda (yield).

### 4. Programación Dinámica
Almacena todos los valores intermedios en un arreglo para acceso rápido.
